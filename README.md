# Decentralised Biogas Production with Centralised Upgrading & Grid Injection

## Project Overview

A techno-economic study of a decentralized biogas production system with centralized biomethane upgrading and grid injection. The project evaluates system sizing, pipeline requirements, digestate transportation, investment and operating costs using an Excel-based engineering model.

## Objectives

- Develop a decentralized biogas production system.
- Study centralized biomethane upgrading and grid injection.
- Estimate pipeline requirements and transportation costs.
- Analyze digestate generation and transportation.
- Perform techno-economic assessment of the proposed system.

## Key Parameters

- Annual green gas production: 9,600,000 m³/year
- Biomethane capacity: 1,200 m³/h
- Operating hours: 8,000 h/year
- Number of digesters: 8
- Pipeline diameter: 200 mm
- Pipeline radius: 3.74 km

## Economic Analysis

The study includes investment cost, depreciation, interest, operating cost, and overall biomethane injection cost.

## Tools Used

- Microsoft Excel
- Engineering calculations
- Techno-economic modelling
